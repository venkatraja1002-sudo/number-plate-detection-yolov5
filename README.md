Deep Learning based Number Plate Detection system using YOLOv5 and EasyOCR with Streamlit web deployment.

# 🚘 Number Plate Detection using YOLOv8 + OCR

## 📌 Project Overview
This project is a Deep Learning-based Number Plate Detection system.  
It detects vehicle number plates using a custom-trained YOLOv8 model and extracts the plate text using EasyOCR.

The application is built using Streamlit for an interactive web interface.

---

## 🧠 Technologies Used

- Python
- YOLOv5 (Ultralytics)
- EasyOCR
- OpenCV
- Streamlit
- NumPy
- PyTorch

---

## 🔍 How It Works

1. User uploads an image.
2. YOLOv5 detects the number plate.
3. The detected plate area is cropped.
4. EasyOCR extracts text from the cropped plate.
5. The extracted number is displayed on the screen.
